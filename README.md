# 💰 ระบบบันทึกและจัดการรายรับ-รายจ่าย

Web App บน Google Apps Script สำหรับบันทึก ติดตาม และวิเคราะห์รายรับ-รายจ่าย
พร้อม Dashboard สรุปยอด และระบบแจ้งเตือนอัตโนมัติทางอีเมล

---

## ✨ ฟีเจอร์หลัก

- 📊 **Dashboard ภาพรวม** — สรุปยอดรายรับ รายจ่าย คงเหลือ และยอดค้างชำระ
- 📈 **กราฟวิเคราะห์** — เปรียบเทียบรายรับ-รายจ่าย, สถานะการจ่าย, สัดส่วนตามหมวดหมู่
- ➕ **บันทึกรายรับ/รายจ่าย** — เลือกจากรายการที่มี หรือพิมพ์เพิ่มใหม่ได้ทันที
- 🔄 **แก้ไข/ลบรายการ** — จัดการข้อมูลย้อนหลังได้ง่าย
- 📧 **แจ้งเตือนอัตโนมัติทางอีเมล**
  - วันที่ 15 → แจ้งรายการค้างชำระกลางเดือน
  - วันที่ 28 → สรุปยอดสิ้นเดือน
  - วันที่ 10 → ล้างรายการที่จ่ายแล้วโดยอัตโนมัติ

---

## 🛠️ เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|------|-----------|
| Backend | Google Apps Script |
| Frontend | HTML5, Bootstrap 5 |
| กราฟ | Chart.js |
| แจ้งเตือน | SweetAlert2 |
| ไอคอน | Font Awesome 6 |
| ฐานข้อมูล | Google Sheets |
